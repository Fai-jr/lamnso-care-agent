# Lamnso Care Agent

A mental-health support agent for Lamnso speakers. Lamnso text is translated to English by a custom
PyTorch model, reasoned over with Zetaris (data layer) and Meterless Nightshift (AI provider, incl. NVIDIA
Nemotron), and answered back in Lamnso.

> Not a substitute for professional care. In an emergency, contact local emergency services.
